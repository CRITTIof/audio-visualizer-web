# SPECTRA · 桌面音频实时频谱

一个本地运行的桌面音频频谱可视化工具，专为 **哔哩哔哩直播姬 / OBS 浏览器源** 设计：

- **透明背景**：叠加层默认不绘制任何底色，画布背景完全透明（Alpha 通道）。
- **监听桌面音频**：在 Chrome / Edge 控制台中共享「整个屏幕」并勾选分享系统音频。
- **实时频率可视化**：柱状频谱、波形声纹、环形频谱三种渲染模式。
- **高自定义**：颜色、渐变、辉光、频率范围、柱数、间距、圆角、镜像、平滑、峰值、布局等均可实时调整，自动保存。
- **端口可修改**：支持 `config.json`、命令行参数、环境变量三种方式。
- **零依赖**：只需要 Node.js，无需安装 npm 包。

仓库地址：<https://github.com/CRITTIof/audio-visualizer-web>

维护者：**Rei Xinglan（CRITTIof）** · <crittiof@outlook.com>

![控制台截图](docs/preview-control.png)

![透明叠加层效果（示意背景）](docs/preview-overlay.png)

> 为什么分成「控制台」和「叠加层」两个页面？
> 浏览器出于安全限制，必须由用户点击并授权后才能采集桌面音频，直播姬的浏览器源无法完成这个授权。
> 因此让 Chrome / Edge 中的控制台负责采集与分析，本地服务再把频谱数据实时转发给直播姬里的透明叠加层。
> 音频不会上传到互联网，所有数据都在本机回环地址内传输。

## 1. 快速开始

要求：**Node.js 18+**，**最新版 Chrome 或 Edge**。

### 获取代码

从 GitHub 克隆仓库：

```bash
git clone https://github.com/CRITTIof/audio-visualizer-web.git
cd audio-visualizer-web
```

也可以直接在 GitHub 页面点击 **Code → Download ZIP**，解压后进入 `audio-visualizer-web` 目录。

### 启动服务

```bash
node server.js
```

也可以直接双击 `start.bat`（Windows），或执行 `bash start.sh`（macOS / Linux）。

启动后终端会显示：

```text
控制台 / 采集端   http://127.0.0.1:8787/
透明叠加层        http://127.0.0.1:8787/overlay.html
```

### 第一步：采集桌面音频

1. 用 Chrome/Edge 打开 **控制台地址**。
2. 点击「共享桌面音频」。
3. 在浏览器弹窗中选择 **整个屏幕**，并打开 **分享系统音频 / 分享音频** 开关。
4. 点击共享。此时控制台预览和叠加层都会出现实时频谱。预览左上角的数据帧率正常应接近 30 FPS。

> 采集页面需要保持打开。现在采集循环由独立的 Web Worker 时钟驱动，即使窗口被最小化或切到游戏后面，通常也会继续以约 30 FPS 更新叠加层。预览左上角的 **FPS 标记** 可以用来确认实时数据帧率。若系统或浏览器开启强省电/效率模式，仍建议让采集页保持可见，或使用下方的 `open-capture.bat` 专用窗口。

> **更稳的后台方案（Windows）**：运行 `open-capture.bat`（可加端口参数，例如 `open-capture.bat 9000`），会使用 Edge/Chrome 的应用窗口模式打开采集页，并关闭后台定时器节流与窗口遮挡节流。这个窗口最小化后仍会持续更新，适合全屏游戏直播。

### 第二步：添加到直播姬 / OBS

1. 在哔哩哔哩直播姬中添加「浏览器」源。
2. URL 填：`http://127.0.0.1:8787/overlay.html`
3. 尺寸建议 **1920 × 1080**。
4. 在浏览器源设置中启用透明背景（不同版本名称可能是「透明」「允许透明背景」「Alpha」等）。
5. 把浏览器源放在场景最上层即可。

也可以直接点击控制台右上角的「打开叠加层」查看独立叠加层，或复制页面中显示的浏览器源地址。

### 没有音频时想先看效果？

- 在控制台点击「演示信号」，会生成用于测试的合成频谱，并同步到叠加层。
- 或直接打开 `http://127.0.0.1:8787/overlay.html?demo=1`，叠加层会自行播放演示动画，方便测试透明背景和尺寸。

## 2. 修改端口

任选一种方式，修改后需要重启服务：

### 方式 A：config.json（推荐）

打开目录下的 `config.json`：

```json
{
  "host": "127.0.0.1",
  "port": 8787,
  "settings": { ... }
}
```

把 `port` 改成例如 `9000`，重启 `node server.js`。控制台和浏览器源地址也会一起变为 `9000`。

### 方式 B：命令行参数

```bash
node server.js --port 9000
```

Windows 双击启动也可以带参数：

```bat
start.bat --port 9000
```

### 方式 C：环境变量

Windows PowerShell：

```powershell
$env:PORT=9000
node server.js
```

macOS / Linux：

```bash
PORT=9000 node server.js
```

优先级：命令行 `--port` > 环境变量 `PORT` > `config.json` > 默认 `8787`。

其他参数：

```bash
node server.js --host 127.0.0.1   # 监听地址，默认只允许本机访问
node server.js --help
```

> 不要用局域网 IP 打开控制台采集桌面音频：浏览器只允许在 `localhost` / `127.0.0.1` 或 HTTPS 页面中调用桌面采集 API。浏览器源可以继续用 `127.0.0.1` 地址。

## 3. 自定义说明

所有修改会 **自动保存到 config.json**，并通过本地服务实时同步给已打开的叠加层。

| 分组 | 可调内容 |
| --- | --- |
| 快速预设 | 霓虹脉冲、极光声纹、声轨环、极简白噪、落日镜像、荧光矩阵 |
| 视觉引擎 | 柱状 / 波形 / 环形；水平与垂直对齐；画面宽高；整体不透明度 |
| 频率与动态 | 柱数、柱间距、最低/最高频率、对数/线性刻度、灵敏度、高频增强、平滑拖尾、噪声门限、最低高度、左右/上下镜像 |
| 形态细节 | 圆角、线宽、波形幅度、波形填充、内圈半径、旋转速度、峰值标记、峰值回落速度 |
| 色彩与光效 | 三段渐变 / 单色 / 彩虹 / 按电平着色；主色、辅色、强调色、峰值色、彩虹饱和度与明度、色相流动、辉光 |
| 背景与其他 | 背景色与背景不透明度（默认 0 = 完全透明）、叠加层状态提示 |

- **频率范围** 只改变显示范围，不会重新采样原始音频，调整后立即生效。
- **灵敏度 / 高频增强** 适合不同音量的直播内容，例如游戏声音偏小或音乐低频过强。
- **左右镜像** 会让低音位于中心，左右对称；**上下镜像** 以中线为轴反射。
- **背景不透明度保持 0** 才是完全透明输出；如果改成大于 0，画面会出现你选择的底色。

### 配置文件示例

`config.json` 中的 `settings` 就是叠加层的全部视觉参数。可以直接手改，然后重启服务；也可以在控制台改，无需手动编辑。

如果同时打开多个控制台标签页，最后一个保存的配置会生效。

## 4. 工作原理

```text
Chrome / Edge 控制台
  Web Worker 时钟（后台不被节流，约 30 次/秒）
        ↓
  getDisplayMedia（桌面音频）
        ↓ Web Audio AnalyserNode（FFT 2048）
  192 段对数频谱 + 波形数据
        ↓ POST /api/frame（本机回环，约 30fps）
Node 本地服务（SSE + TCP no-delay）
        ↓ Server-Sent Events（SSE）
直播姬 / OBS 浏览器源（/overlay.html）
  Canvas 透明渲染
```

- 服务默认只监听 `127.0.0.1`，不对外网开放。
- 音频本身不会被发送到服务端；服务只转发计算后的频谱数组。
- 不依赖任何第三方 npm 包、云服务或账号。

## 5. 常见问题

**没有声音 / 频谱没有反应**

- 重新点击「共享桌面音频」，选择 **整个屏幕**，确认勾选了「分享系统音频」。
- 某些浏览器版本只在共享「屏幕」时提供系统音频选项，共享单个窗口时可能没有声音。
- 如果系统没有开启立体声混音，或者浏览器版本过旧，可以改用「麦克风」模式，或使用支持系统音频回环的 Chrome / Edge 最新版本。
- 确认控制台里的音量条有反应；没有反应说明浏览器没有拿到音频轨道。

**直播姬中透明背景变成黑色 / 白色**

- 确认填的是 `/overlay.html`，不是控制台 `/`。
- 在浏览器源设置中开启透明背景选项。
- 确认控制台「背景不透明度」为 0。
- 某些直播姬版本对透明浏览器源支持有限，可改用 OBS 的浏览器源测试，或升级直播姬。

**叠加层一直显示“等待桌面音频”**

- 控制台页面是否还开着，并且仍在采集中？
- 控制台的连接状态是否显示「本地服务已连接」？
- 叠加层地址的端口是否与控制台一致？控制台页面里复制的地址最可靠。

**修改控制台参数后叠加层没变化**

- 正常情况下 1 秒内会实时同步。若没有，刷新一下浏览器源。
- 如果直播姬缓存了页面，重新加载浏览器源或重启浏览器源。

**端口被占用**

终端会提示占用。换端口即可：

```bash
node server.js --port 8788
```

**双击 start.bat 后窗口一闪而过**

- v1.1 已修复 Windows 批处理换行导致 `cmd.exe` 报「命令语法不正确」而闪退的问题；现在服务退出后窗口会保持打开并显示退出码。
- 如果仍然闪退，可以在项目文件夹的地址栏输入 `cmd` 回车，再执行 `start.bat`，这样能看到完整错误。
- 常见原因：端口被占用、Node.js 未安装、`config.json` 不是合法 JSON。

**采集页面最小化后频谱卡顿 / FPS 很低**

- 本工具已经用 Web Worker 时钟绕开 Chrome 对后台标签页的 `setInterval` 节流；正常情况下即使最小化也能保持约 30 FPS。
- 先看采集预览左上角的 **FPS**：如果长期低于 10，可能是浏览器的「效率模式 / 内存节省」或系统省电模式在限制后台。将采集页保持可见，或在浏览器设置中把 `127.0.0.1` 加入性能例外。
- Windows 用户还可以运行 `open-capture.bat`，使用已关闭后台节流的专用 Chrome/Edge 窗口采集。
- 如果刚更新过文件，请刷新采集页和叠加层浏览器源，让新的计时器与渲染脚本生效。

**想在没有采集页时测试叠加层**

打开 `http://127.0.0.1:8787/overlay.html?demo=1`，这是纯前端演示数据，不需要音频权限。

## 6. 文件结构

```text
desktop-audio-visualizer/
├─ server.js              # 本地 HTTP + SSE 服务（零依赖）
├─ config.json            # 端口、监听地址与视觉参数
├─ start.bat              # Windows 启动脚本
├─ open-capture.bat       # Windows：打开关闭后台节流的专用采集窗口
├─ start.sh               # macOS / Linux 启动脚本
├─ package.json
├─ README.md
├─ LICENSE
├─ docs/                  # README 预览截图
└─ public/
   ├─ index.html          # 控制台 / 桌面音频采集端
   ├─ overlay.html        # 透明叠加层（放入浏览器源）
   ├─ overlay.css
   ├─ styles.css
   ├─ settings.js         # 设置 schema、校验、预设（前后端共用）
   ├─ visualizer.js       # Canvas 渲染器
   ├─ demo-signal.js      # 合成演示信号
   ├─ ticker-worker.js    # 后台不被节流的高精度采集时钟
   ├─ app.js              # 控制台逻辑与音频采集
   └─ overlay.js          # 叠加层逻辑（SSE 接收）
```

## 7. 快捷操作

- 控制台顶部会显示叠加层连接数量，方便确认直播姬是否成功加载页面。
- 「复制地址」会复制当前端口对应的浏览器源 URL。
- 「全屏」按钮用于在浏览器中全屏检查视觉布局。
- 所有设置自动保存在本地，无需注册或手动导出。
